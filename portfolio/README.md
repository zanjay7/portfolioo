# Sanjay Krishnan | Portfolio

Personal portfolio built with plain HTML, CSS and JavaScript. No build step.

## Files
- `index.html` page content
- `style.css` styles
- `script.js` interactions (3D keyboard, sounds, smooth scroll)
- `Sanjay_Krishnan_Resume.pdf` resume download

## Run locally
Open `index.html` in a browser, or run `npx serve .`

## Deploy
Import the repo on vercel.com. Framework preset: Other. Leave build and output settings empty.
